El registro de adopciones muestra animales que no están disponibles para adoptar o que ya estan adoptados

Hecho
-Alta animales
-Alta familias
-Alta empresas
-Realizar adopción
-Realizar donación
-Cambio de estado
-Recuperar datos
-Autores
-Salir
-Generación de página
-Menú principal
-Anular adopción
-Importar donaciones
-Consulta de familia

-Video (Pepe)
